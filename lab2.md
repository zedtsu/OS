## 1. Подготовка виртуальной машины
1. **Создание ВМ**: Архитектура `x86_64`, выделено жесткий диск (VDI/VMDK) и CD-привод.
2. **Аппаратная поддержка**: В настройках процессора ВМ (и в BIOS хоста) включена виртуализация `VT-x/AMD-V`.
3. **Сеть**: Тип подключения изменен на **Сетевой мост (Bridge)** для получения прямого IP-адреса из локальной сети.
4. **Запуск**: Подключен образ `SystemRescue CD 64-bit`, выполнена загрузка в консоль.

---

## 2. Подготовка дискового пространства и сети
Перед началом бутстраппинга проверяем связь и размечаем накопитель:

```bash
# Проверка сетевого соединения
ping -c 3 google.com

# Поиск имени целевого диска (например, /dev/sda)
lsblk

# Создание таблицы разделов (GPT) и корневого раздела
cfdisk /dev/sda

# Форматирование созданного раздела /dev/sda1 в ext4
mkfs.ext4 /dev/sda1

# Монтирование будущего корня в точку /mnt
mount /dev/sda1 /mnt
```

## 3. Бутстраппинг операционной системы (на выбор)

### Вариант А: Начальный уровень (Debian / Ubuntu)
```bash
# Развертывание базовой системы Debian в директорию /mnt
debootstrap --arch amd64 stable /mnt http://debian.org

# Монтирование виртуальных файловых систем для корректной работы chroot
mount --bind /sys /mnt/sys
mount --bind /proc /mnt/proc
mount --bind /dev /mnt/dev
mount --bind /dev/pts /mnt/dev/pts

# Вход в изолированное окружение установленной системы
chroot /mnt /bin/bash
```

### Вариант Б: Средний уровень (Arch Linux)
```bash
# Установка базовых пакетов, ядра и прошивок через pacstrap
pacstrap -K /mnt base linux linux-firmware nano dhcpcd openssh grub

# Генерация таблицы монтирования fstab
genfstab -U /mnt >> /mnt/etc/fstab

# Вход в окружение установленной системы
arch-chroot /mnt
```

## 4. Настройка конфигурации (внутри chroot)

Выполните базовые настройки операционной системы перед первой перезагрузкой:

```bash
# 1. Смена пароля суперпользователя root
passwd

# 2. Создание пользователя user
useradd -m -g users -G wheel -s /bin/bash user

# 3. Установка пароля "123456" для созданного пользователя
echo "user:123456" | chpasswd

# 4. Настройка системного времени (пример для Москвы)
ln -sf /usr/share/zoneinfo/Europe/Moscow /etc/localtime
hwclock --systohc

# 5. Установка и конфигурация загрузчика GRUB
# (Для Debian сначала выполните: apt update && apt install grub-pc)
grub-install /dev/sda
grub-mkconfig -o /boot/grub/grub.cfg
```

---

## 5. Настройка SSH-сервера и сети

```bash
# Установка SSH-сервера (если не был установлен ранее)
# Debian: apt install openssh-server
# Arch: pacman -S openssh

# Разрешение аутентификации по паролю
# Убедитесь, что в /etc/ssh/sshd_config раскомментирована строка:
# PasswordAuthentication yes

# Включение автозапуска демона sshd при старте системы
systemctl enable sshd

# Настройка автоматического получения IP-адреса при загрузке
# Для Arch (dhcpcd):
systemctl enable dhcpcd

# Выход из chroot, размонтирование дисков и перезагрузка ВМ
exit
umount -R /mnt
reboot
```

## 6. Проброс портов и проверка доступа

1. **Определение IP**: После перезагрузки ВМ авторизуйтесь под `user` и узнайте внутренний IP-адрес команды `ip a`.
2. **Маршрутизатор**: Откройте веб-интерфейс вашего роутера и перейдите в раздел **Port Forwarding (Перенаправление портов)**.
3. **Правило проброса**:
   * **Внешний порт**: `7022`
   * **Внутренний порт**: `22`
   * **Протокол**: `TCP`
   * **Внутренний IP-адрес**: [IP-адрес вашей виртуальной машины]
4. **Тест**: Проверка подключения внешней командой:
   ```bash
   ssh -p 7022 user@<ваш_внешний_IP_адрес>
   ```

## 7. Способы записи отчета (консоли)

Для демонстрации процесса без записи тяжелых видеофайлов рекомендуется использовать один из вариантов:

1. **Asciinema (Оптимально)**: Записывает сессию терминала прямо в текстовом виде. Плеер можно встроить в HTML/Markdown.
2. **Утилита `script`**: Встроенный инструмент. Запустите `script lab2_record.log` перед началом. Весь ввод и вывод терминала запишется в текстовый файл.
3. **Встроенная запись VirtualBox**: Включается в меню *Настройки ВМ -> Экран -> Запись видео*.
